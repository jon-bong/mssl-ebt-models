    Mssl.Ebt.Models.Messages.General Namespace

    The namespace for all classes representing routine EBT transaction messages.

    Classes

    ChangeComplete A Change Complete notification that EBT sends to the initiator of a transaction such as a Consumer Transfer Request.
    ChangePending A Change Pending notification that is sent by the EBT to a system participant.
    NewDataRequired A New Action Date Required Notification that is sent by the EBT to the appropriate system participant.
    NewDate Submitted by a system participant in response to a New Action Date Required Notification.
    TerminationNotification A Termination Notice submitted by a system participant.
    TerminationTransactionAcknowledgement a Termination Transaction Acknowledgment sent by a system participant in response to a TransactionTerminatedNotification termination message that the EBT has sent to the system participant.
    TransactionAcknowledgement A Transaction Acknowledgment sent by a system participant in response to a message that the EBT has sent to the system participant.
    TransactionTerminatedNotification A Transaction Terminated Notification which is sent to system participants to inform them that a request has been terminated.
    ValidationAcknowledgement A Validation Acknowledgment sent to a system participant in response to a transaction that the system participant has sent to the EBT.
    ValidationError An error returned by the EBT in response to a transaction sent by the System Participant.
