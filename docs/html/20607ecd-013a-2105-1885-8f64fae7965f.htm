    ValidationError Properties

    Properties

    ErrorAttribute The name of the attribute with which the error was encountered.
    ErrorCode A code that identifies the type of error encountered. Possible values are
    • FAILED BUSINESS VALIDATION
    • FAILED MANDATORY VALIDATION
    • FAILED MULTIPLE TRANSACTION VALIDATION
    • UNRECOGNISED VALUE
    • ILL-FORMED MESSAGE
    ErrorValue The value that was supplied for ErrorAttribute that failed.
