    ConsumerHistory Properties

    Properties

    AccountNumber The MSSL account for the consumer.
    ConsumerName The name of the consumer account.
    DeliveryMethod The usage data delivery method. This must be Electronic.
    EbtTransactionID An EBT Transaction ID consisting of the 10-digit Market Participant account number starting with 930 and a 6-character alphanumeric number left-padded with zeros, separated by a colon.
    (Inherited from EbtMessage)
    IntendedRecipient The recipient of the consumer history data. Where the sending party type is SupplierElectronic, this must be the same as the sending party ID.
    PeriodFrom The From date of the Consumer History Request.
    PeriodFromString The string equivalent of PeriodFrom in yyyyMMdd format.
    PeriodTo The To date of the Consumer History Request.
    PeriodToString The string equivalent of PeriodTo in yyyyMMdd format.
    SendingPartyType For an EMC/DRA initiated request the value is SupplierElectronic indicating Supplier Electronic. For a DMP initiated request the value is ConsumerElectronic indicating Consumer Electronic.
    UserID Identifies the user who sent the message.
