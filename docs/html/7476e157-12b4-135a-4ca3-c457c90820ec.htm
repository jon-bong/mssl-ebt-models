    PricingData Properties

    Properties

    Compressed Indicates whether the data communicated has been compressed. Value is fixed at No.
    ContentFormat An indication of the format of the data to be communicated. Value is fixed as CSV.
    Data The actual data to be communicated i.e. the USEP, HEUC, MEUC, AFP and VCRP price data in 5 comma-separated lines after a header line.
    SendingPartyType An identification of how the communication has been initiated, fixed at SupplierElectronic.
    TransactionID A unique transaction ID indicating the communication transaction that the message is part of.
    UserID This field identifies the user who sent the message.
