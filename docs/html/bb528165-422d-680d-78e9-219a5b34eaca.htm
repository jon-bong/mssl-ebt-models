    TerminationNotification Properties

    Properties

    AccountNumber The MSSL account number for the consumer. For Non Market to Market - Consumer transfer request, the account number provided should be the EBS account number.
    ConsumerName The name of the consumer account.
    EbtTransactionID An EBT Transaction ID consisting of the 10-digit Market Participant account number starting with 930 and a 6-character alphanumeric number left-padded with zeros, separated by a colon.
    (Inherited from EbtMessage)
    SendingPartyType For an NMPR/MPR/EMC initiated request the value is SupplierElectronic indicating Supplier Electronic. For a DMP initiated request the value is ConsumerElectronic indicating Consumer Electronic.
    UserID Identifies the user who sent the message.
